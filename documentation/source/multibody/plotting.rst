Plotting package
================

This package is accessed through `multibody.plot` and it allows plotting figures using 
`plot_multibody_system` method or animations using `animate_multibody`. The method 
`pltTemplate` just has a set of predefined colors that work well with slides and have 
a light and dark backgrounds. None of these are fully black or fully white.
