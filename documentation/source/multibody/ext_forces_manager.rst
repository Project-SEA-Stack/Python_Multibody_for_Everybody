ExtForcesManager package
===========================

The `ExtForcesManager` handles coupling between the multibody core and external‐force models  
(e.g. MoorDyn lines, wave loads, etc.). The multibody framework provides state variables 
such as position and velocity, whereas the external modules provide applied forces.
